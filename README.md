# Giải ngân Chương trình MTQG – tỉnh Cao Bằng

Trang thống kê tình hình thực hiện, giải ngân các Chương trình mục tiêu quốc gia, dành cho lãnh đạo theo dõi nhanh trên máy tính và điện thoại.

- Địa chỉ: https://luchongky.github.io/giainganmtqg/
- Nguồn số liệu: Web App "Bộ lọc & Tổng hợp Chương trình MTQG" (Google Apps Script), gọi qua `?api=init` và `?api=report&nam=&thang=`. Số liệu tự cập nhật khi nạp dữ liệu mới vào Bộ lọc MTQG.
- Đơn vị tính trên trang: tỷ đồng (ô tổng hợp), triệu đồng (bảng chi tiết).
- Đổi nguồn số liệu: sửa biến `API_URL` ở đầu phần `<script>` trong `index.html`.

Biên soạn: Lục Hồng Kỳ – Sở Tài chính tỉnh Cao Bằng.
